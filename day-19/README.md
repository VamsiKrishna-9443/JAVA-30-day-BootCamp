# 2. File Handling

## Definition

**File handling** is the process of creating, reading, writing, updating, copying, moving, and deleting files or directories through a program.

Java has file APIs mainly in:

```java
java.io
java.nio.file
```

For modern Java applications, `java.nio.file.Path` and `java.nio.file.Files` are especially important.

---

# 3. `Path`

## Definition

`Path` represents the **location of a file or directory** in the file system.

Think of:

```text
Path  = Where is it?
Files = What should I do with it?
```

Example:

```java
Path path = Path.of("data", "employees", "employees.csv");
```

The `Path` object represents the location. It does not itself read or write the file.

---

## Creating a Path

### `Path.of()`

```java
Path path = Path.of("employees.csv");
```

Multiple path components can be supplied:

```java
Path path = Path.of(
        "data",
        "employees",
        "employees.csv"
);
```

This is preferred over manually joining strings because Java handles platform-specific path separators.

---

# 4. Important `Path` Methods

## `getFileName()`

Returns the final component of the path.

```java
Path path = Path.of(
        "data", "employees", "employees.csv"
);

System.out.println(path.getFileName());
```

Output:

```text
employees.csv
```

---

## `getParent()`

Returns the parent path.

```java
System.out.println(path.getParent());
```

Output:

```text
data/employees
```

---

## `getRoot()`

Returns the root of the path.

```java
System.out.println(path.getRoot());
```

For a relative path, the result is usually:

```text
null
```

For example, a Windows absolute path may have a root similar to:

```text
C:\
```

### Why can `getRoot()` be `null`?

Because:

```java
Path path = Path.of("data", "employees", "employees.csv");
```

is a **relative path**.

It does not start from a file-system root.

An absolute path contains a root:

```java
Path path = Path.of("C:\\data\\employees\\employees.csv");
```

---

## `toAbsolutePath()`

Converts a relative path into an absolute path.

```java
System.out.println(path.toAbsolutePath());
```

---

## `resolve()`

Combines two paths.

```java
Path folder = Path.of("data");

Path file = folder.resolve("employees.csv");

System.out.println(file);
```

Output:

```text
data/employees.csv
```

This is much safer and clearer than:

```java
"data/" + "employees.csv"
```

---

## `normalize()`

Removes unnecessary `.` and `..` path components.

```java
Path path =
        Path.of("data/employees/../employees/employees.csv");

System.out.println(path.normalize());
```

---

## `startsWith()`

Checks whether the path starts with a specified path.

```java
boolean result = path.startsWith("data");
```

---

## `endsWith()`

Checks whether the path ends with a specified path.

```java
boolean result = path.endsWith("employees.csv");
```

---

## `toString()`

Returns the path as a string.

```java
String value = path.toString();
```

---

## `isRegularFile()`

Checks whether the path is a normal file.


---

## `isDirectory()`

Checks whether the path is a directory.

```java
Files.isDirectory(path);
```

---

## `createFile()`

Creates a new file.

```java
Files.createFile(path);
```

---

## `createDirectory()`

Creates one directory.

```java
Files.createDirectory(path);
```

---

## `createDirectories()`

Creates the directory and all missing parent directories.

```java
Files.createDirectories(path);
```

Example:

```java
Files.createDirectories(
        Path.of("data", "employees", "backup")
);
```

---

## `writeString()`

Writes a complete string to a file.

```java
Files.writeString(
        path,
        "101,Vamsi,50000"
);
```

This is convenient for simple text-file operations.

---

## `readString()`

Reads the entire text file as one `String`.

```java
String content = Files.readString(path);
```

---

## `readAllLines()`

Reads all lines into a `List<String>`.

```java
List<String> lines = Files.readAllLines(path);
```

Example:

```java
for (String line : lines) {
    System.out.println(line);
}
```

This is convenient for relatively small text files.

---

## `write()`

Writes a collection of lines.

```java
List<String> lines = List.of(
        "101,Vamsi,50000",
        "102,Rahul,60000"
);

Files.write(path, lines);
```

---

## `copy()`

Copies one file to another location.

```java
Files.copy(source, destination);
```

To replace an existing destination:

```java
Files.copy(
        source,
        destination,
        StandardCopyOption.REPLACE_EXISTING
);
```

---

## `move()`

Moves or renames a file.

```java
Files.move(source, destination);
```

---

## `delete()`

Deletes a file or an empty directory.

```java
Files.delete(path);
```

---

## `deleteIfExists()`

Deletes the path only when it exists.

```java
Files.deleteIfExists(path);
```

---

## `newBufferedReader()`

Creates a `BufferedReader` for a text file.

```java
BufferedReader reader =
        Files.newBufferedReader(path);
```

---

## `newBufferedWriter()`

Creates a `BufferedWriter` for a text file.

```java
BufferedWriter writer =
        Files.newBufferedWriter(path);
```

# 7. `Files` Demo

`FileDemo.java` demonstrates common file operations:

```java
package day19.files;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardCopyOption;
import java.util.List;

public class FileDemo {

    public static void main(String[] args) {

        Path folder = Path.of("data", "files");
        Path file = folder.resolve("employees.txt");

        try {
            Files.createDirectories(folder);

            if (!Files.exists(file)) {
                Files.createFile(file);
            }

            System.out.println(
                    "File exists: " + Files.exists(file)
            );

            System.out.println(
                    "Is regular file: "
                            + Files.isRegularFile(file)
            );

            System.out.println(
                    "Is directory: "
                            + Files.isDirectory(file)
            );

            Files.writeString(
                    file,
                    "101,Vamsi,50000\n"
                            + "102,Rahul,60000\n"
                            + "103,Krishna,70000"
            );

            System.out.println("\nRead as String:");
            System.out.println(Files.readString(file));

            System.out.println("\nRead All Lines:");

            List<String> lines =
                    Files.readAllLines(file);

            for (String line : lines) {
                System.out.println(line);
            }

            Path backup =
                    folder.resolve("employees-backup.txt");

            Files.copy(
                    file,
                    backup,
                    StandardCopyOption.REPLACE_EXISTING
            );

            System.out.println("\nFile copied.");

            Path movedFile =
                    folder.resolve("employees-moved.txt");

            Files.move(
                    backup,
                    movedFile,
                    StandardCopyOption.REPLACE_EXISTING
            );

            System.out.println("File moved.");

            Files.deleteIfExists(movedFile);

            System.out.println("Moved file deleted.");

        } catch (IOException e) {

            System.out.println(
                    "File operation failed: "
                            + e.getMessage()
            );
        }
    }
}
```

# 8. Buffered I/O

## Definition

**Buffered I/O** means using an in-memory buffer between the Java program and the underlying input/output source.

Instead of repeatedly communicating with the file system for small operations, data is handled through a buffer.

Conceptually:

```text
Without buffering:

Java → File
Java → File
Java → File
Java → File


With buffering:

Java
 ↓
Buffer
 ↓
File
```

Buffered I/O is especially useful when processing text files and streams.

---

# 9. `BufferedReader`

## Definition

`BufferedReader` reads character data efficiently and provides convenient line-based reading.

Package:

```java
java.io.BufferedReader
```

It is commonly used with:

```java
FileReader
```

or:

```java
Files.newBufferedReader()
```

---

## Important `BufferedReader` Methods

### `read()`

Reads a single character.

```java
int value = reader.read();
```

The returned value is an integer representation of the character, or `-1` at end-of-stream.

---

### `readLine()`

Reads one complete line.

```java
String line = reader.readLine();
```

Returns `null` when the end of the file is reached.

Typical pattern:

```java
String line;

while ((line = reader.readLine()) != null) {
    System.out.println(line);
}
```

---

### `ready()`

Checks whether the reader is ready to be read.

```java
reader.ready();
```

---

### `skip()`

Skips a number of characters.

```java
reader.skip(5);
```

---

### `close()`

Closes the reader.

```java
reader.close();
```

When using try-with-resources, explicit closing is normally unnecessary.

```java
writer.write("Hello Java");
```

---

```java

```

---

### `flush()`


---

### `close()`


# 11. Try-With-Resources

## Definition

**Try-with-resources** automatically closes resources that implement `AutoCloseable`.

Instead of:

```java
BufferedReader reader = ...;

try {
    // use reader
} finally {
    reader.close();
}
```

use:

```java
try (BufferedReader reader = ...) {
    // use reader
}
```

Java automatically closes the reader when the block finishes, even when an exception occurs.

This is the preferred pattern for file I/O.

# 12. Buffered I/O Demo

`BufferedIODemo.java` demonstrates writing and reading text:

```java
package day19.bufferedio;

import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.FileReader;
import java.io.FileWriter;
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;

public class BufferedIODemo {

    public static void main(String[] args) {

        Path path =
                Path.of("data", "buffered", "employees.txt");

        try {
            Files.createDirectories(path.getParent());

            // WRITE
            try (BufferedWriter writer =
                         new BufferedWriter(
                                 new FileWriter(path.toFile())
                         )) {

                writer.write("101,Vamsi,50000");
                writer.newLine();

                writer.write("102,Rahul,60000");
                writer.newLine();

                writer.write("103,Krishna,70000");
                writer.newLine();

                writer.flush();
            }

            System.out.println(
                    "Data written successfully."
            );

            // READ
            try (BufferedReader reader =
                         new BufferedReader(
                                 new FileReader(path.toFile())
                         )) {

                String line;

                while ((line = reader.readLine()) != null) {
                    System.out.println(line);
                }
            }

        } catch (IOException e) {

            System.out.println(
                    "I/O error: "
                            + e.getMessage()
            );
        }
    }
}
```

# 13. Append Mode

Normal `FileWriter` usage can overwrite the file content:

```java
new FileWriter(path.toFile());
```

For append mode:

```java
new FileWriter(path.toFile(), true);
```

Example:

```java
try (BufferedWriter writer =
             new BufferedWriter(
                     new FileWriter(path.toFile(), true)
             )) {

    writer.write("104,Arjun,65000");
    writer.newLine();
}
```

The `true` enables append mode.

# 15. Serialization

## Definition

**Serialization is the process of converting an object's state into a byte stream so that it can be stored or transmitted.**

Concept:

```text
Java Object
     ↓
Serialization
     ↓
Byte Stream
     ↓
File / Network
```

The reverse process is called **deserialization**:

```text
Byte Stream
     ↓
Deserialization
     ↓
Java Object
```

---

# 16. Why Serialization?

Java objects normally exist in memory.

Example:

```java
Employee employee =
        new Employee(101, "Vamsi", 50000);
```

When the program terminates, the in-memory object disappears.

Serialization allows the object's state to be stored so that it can later be restored.

```text
Employee object
      ↓
employee.ser
```

Later:

```text
employee.ser
      ↓
Employee object
```

---

# 17. `Serializable`

A class must implement:

```java
java.io.Serializable
```

Example:

```java
public class Employee implements Serializable {
}
```

`Serializable` is a **marker interface**. It does not require implementation of methods.

---

# 18. `serialVersionUID`

A serializable class commonly declares:

```java
private static final long serialVersionUID = 1L;
```

It is used during deserialization as a version identifier to help determine whether the serialized object is compatible with the current class definition.

# 21. `transient`

Use `transient` when a field should not participate in default Java serialization.

Example:

```java

```

After deserialization, a transient reference field gets its default value, such as `null`.

```java
import java.io.Serializable;

public class Employee implements Serializable {

    private static final long serialVersionUID = 1L;
```

`serialization/SerializationDemo.java`:

```java
package day19.serialization;

import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.IOException;
import java.io.ObjectInputStream;
import java.io.ObjectOutputStream;
import java.nio.file.Files;
import java.nio.file.Path;

public class SerializationDemo {

    public static void main(String[] args) {

        Path path =
                Path.of(
                        "data",
                        "serialization",
                        "employee.ser"
                );

        Employee employee =
                new Employee(
                        101,
                        "Vamsi",
                        50000,
                        "secret123"
                );

        // SERIALIZATION
        try {
            Files.createDirectories(path.getParent());

            try (ObjectOutputStream out =
                         new ObjectOutputStream(
                                 new FileOutputStream(
                                         path.toFile()
                                 )
                         )) {

                out.writeObject(employee);
            }

            System.out.println(
                    "Employee serialized successfully."
            );

        } catch (IOException e) {

            System.out.println(
                    "Serialization error: "
                            + e.getMessage()
            );
        }

        // DESERIALIZATION
        try (ObjectInputStream in =
                     new ObjectInputStream(
                             new FileInputStream(
                                     path.toFile()
                             )
                     )) {

            Employee restoredEmployee =
                    (Employee) in.readObject();

            System.out.println(
                    "Restored employee:"
            );

            System.out.println(restoredEmployee);

        } catch (IOException |
                 ClassNotFoundException e) {

            System.out.println(
                    "Deserialization error: "
                            + e.getMessage()
            );
        }
    }
}
```

Because `password` is `transient`, its serialized value is not restored.

# 23. CSV

## Definition

**CSV** stands for **Comma-Separated Values**.

It is a simple text format for representing tabular data.

Example:

```text
id,name,salary
101,Vamsi,50000
102,Rahul,60000
103,Krishna,70000
```

The first line is commonly a header:

```text
id,name,salary
```

The remaining lines are records.

```text
101,Vamsi,50000
```

can be interpreted as:

```text
id     = 101
name   = Vamsi
salary = 50000
```

# 26. Employee CSV Export

`EmployeeCsvExporter.java` is responsible for:

```text
List<Employee>
      ↓
CSV file
```

Core approach:

```java
package day19.employee;

import java.io.BufferedWriter;
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;

public class EmployeeCsvExporter {

    public void export(
            List<Employee> employees,
            Path path) throws IOException {

        if (path.getParent() != null) {
            Files.createDirectories(path.getParent());
        }

        try (BufferedWriter writer =
                     Files.newBufferedWriter(path)) {

            writer.write("id,name,salary");
            writer.newLine();

            for (Employee employee : employees) {

                writer.write(
                        employee.getId()
                                + ","
                                + employee.getName()
                                + ","
                                + employee.getSalary()
                );

                writer.newLine();
            }
        }
    }
}
```

# 27. Employee CSV Import

`EmployeeCsvImporter.java` is responsible for:

```text
CSV file
    ↓
BufferedReader
    ↓
CSV line
    ↓
split(",")
    ↓
parse values
    ↓
Employee
```

Example implementation:

```java
package day19.employee;

import java.io.BufferedReader;
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.ArrayList;
import java.util.List;

public class EmployeeCsvImporter {

    public List<Employee> importEmployees(
            Path path) throws IOException {

        List<Employee> employees =
                new ArrayList<>();

        try (BufferedReader reader =
                     Files.newBufferedReader(path)) {

            String header = reader.readLine();

            if (header == null) {
                return employees;
            }

            String line;
            int lineNumber = 1;

            while ((line = reader.readLine()) != null) {

                lineNumber++;

                if (line.isBlank()) {
                    continue;
                }

                try {
                    String[] data =
                            line.split(",");

                    // Expected columns:
                    // id, name, salary
                    if (data.length != 3) {

                        System.out.println(
                                "Invalid row at line "
                                        + lineNumber
                                        + ": "
                                        + line
                        );

                        continue;
                    }

                    int id =
                            Integer.parseInt(
                                    data[0].trim()
                            );

                    String name =
                            data[1].trim();

                    double salary =
                            Double.parseDouble(
                                    data[2].trim()
                            );

                    if (name.isEmpty()) {

                        System.out.println(
                                "Invalid employee name at line "
                                        + lineNumber
                        );

                        continue;
                    }

                    employees.add(
                            new Employee(
                                    id,
                                    name,
                                    salary
                            )
                    );

                } catch (NumberFormatException e) {

                    System.out.println(
                            "Invalid number at line "
                                    + lineNumber
                                    + ": "
                                    + line
                    );
                }
            }
        }

        return employees;
    }
}
```

# 29. Error Handling in CSV Import

A reliable import process should not crash because of one bad row.

Consider:

```text
id,name,salary
101,Vamsi,50000
102,Rahul,ABC
103,Krishna,70000
INVALID
104,Anil,55000
105,,60000
106,Ramesh,75000
```

Possible problems:

| Problem | Example | Exception/Validation |
|---|---|---|
| Invalid numeric ID | `ABC,Vamsi,50000` | `NumberFormatException` |
| Invalid salary | `102,Rahul,ABC` | `NumberFormatException` |
| Wrong number of columns | `INVALID` | Manual validation |
| Empty name | `105,,60000` | Manual validation |
| Missing file | File does not exist | `IOException` / specific file exception |
| File access problem | Permission denied | `IOException` |
| Empty file | No header/data | Manual handling |

The importer should report the problem and continue when possible.

Example:

```text
Imported: Vamsi
Invalid number at line 3: 102,Rahul,ABC
Imported: Krishna
Invalid row at line 5: INVALID
Invalid employee name at line 7
Imported: Ramesh
```

# 33. Key Differences

## Path vs Files

```text
Path
  = Represents a location

Files
  = Performs operations on that location
```

Example:

```java
Path path = Path.of("employees.csv");

Files.readString(path);
```

---

## BufferedReader vs BufferedWriter

```text
BufferedReader
  = Reads text

BufferedWriter
  = Writes text
```

---

## Serialization vs CSV

### CSV

```text
101,Vamsi,50000
```

- Text-based
- Human-readable
- Easy to inspect
- Useful for exchanging tabular data

### Java Serialization

```text
Employee object
        ↓
byte stream
        ↓
employee.ser
```

- Object-state oriented
- Binary representation
- Used to store/restore Java object state

# 39. Day 19 Takeaway

> **Path** represents where a file or directory is located.

> **Files** performs operations such as create, read, write, copy, move, and delete.

> **Buffered I/O** uses a memory buffer for efficient text input/output.

> **BufferedReader** reads text, especially line by line.

> **BufferedWriter** writes text efficiently.

> **Try-with-resources** automatically closes I/O resources.

> **CSV** is a text format commonly used for tabular data.

> **Serialization** converts Java object state into a byte stream.

> **Deserialization** reconstructs the object from the byte stream.

> **Error handling** makes file-processing programs reliable and prevents one bad record from terminating the entire import.
