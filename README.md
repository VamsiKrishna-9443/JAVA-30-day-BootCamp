### ⚡ Key Techniques

#### HashMap

Used for:

* Fast lookup
* Frequency counting
* Duplicate detection
* Character frequency
* Complement lookup

Typical complexity:

```text
Average Lookup → O(1)
Insertion       → O(1)
```

#### Two-Pointer

Used for problems where two indexes can process an array/string efficiently.

Typical pattern:

```text
left  → ---------------- ← right
```

Pointers move according to the condition until the required result is found.
