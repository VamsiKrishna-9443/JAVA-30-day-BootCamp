This repository contains my **30-Day Java Developer Bootcamp** journey.

The bootcamp is designed to take a developer from **Java Fundamentals → OOP → Collections → Streams → Concurrency → JDBC → Spring Boot → REST API Development**.

🎯 **Goal:** Become a strong **Java Backend Developer** through daily coding, problem-solving, and project-based learning.
